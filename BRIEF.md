# Build brief: xlsxops

Build a Python library "xlsxops": reliable Excel (.xlsx) operations that an LLM agent calls as tools. Common rules: Python 3.12, works on Windows and Linux. Allowed dependencies only: openpyxl, python-docx, docxcompose, python-pptx, pypdf, pdfplumber, fpdf2, pandas, numpy, jsonschema. No network, no telemetry, no subprocess, no Office automation. Every public operation is a plain function that returns a JSON-serializable report {"ok", "changed", "warnings", "details"} and never raises for user errors. Each ships a JSON Schema in SCHEMAS[name], at most 600 characters. Pytest tests generate their own fixtures. Apache-2.0.

Operations (each must keep existing styles, number formats, column widths, other sheets, defined names and charts intact):
read_summary (sheets, used ranges, headers, row counts, 5 sample rows, formulas count), write_cells, add_sheet, add_column, calculated_column (formula per row with relative refs), set_formula, total_row (SUM/AVERAGE/COUNT under a table), sort (multi-key, header-aware), filter_rows to a new sheet, dedupe (by key columns, report removed rows), split_column (by delimiter or regex into new columns), lookup (VLOOKUP/XLOOKUP-style join from another sheet, written as formulas or values), pivot_summary (group-by with sum/count/avg into a new sheet, as values plus an optional formula version), chart (bar/line/pie/scatter from a range, title and axis titles, placed without overlap), conditional_format (color scale, data bar, cell-is rules, highlight outliers by z-score), data_validation (list, whole number, date), format_range (number format, bold header, freeze panes, autofit width estimate), from_csv (with type inference: numbers, dates, leading zeros kept as text), multisheet_report (one sheet per group).

Formula safety: include a small pure-Python evaluator for SUM, AVERAGE, COUNT, COUNTA, COUNTIF(S), SUMIF(S), AVERAGEIF, MIN, MAX, IF, IFERROR, ROUND, VLOOKUP, XLOOKUP, INDEX, MATCH, TEXT, and arithmetic. After any write, verify_formulas(path) evaluates every formula it understands and reports #REF!, circular references and type errors, and lists the formulas it could not evaluate. openpyxl does not compute values, so cached values must be written for the formulas it can evaluate, so files opened without recalculation show numbers.

Tests: one per operation, plus a round trip that proves styles, charts and other sheets survive, plus a verify_formulas test with a broken reference.
